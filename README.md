# Rewsta-React
This project began as the CofD X project in Flutter. It began as a web version in PHP, before then moving to a Flutter app and then finally this rebranded React version. It was originally built for internal communications but later became part of a brand I hoped to build. The goal was a social media app with a similar layout to Twitter (X), but focused on only showing posts from people you follow, on a chronological only feed. The idea was to strip away the ads and algorithms that make social media unenjoyable, and focus it on news bulletin updates, as they happen on a clean feed. The app also included direct messaging, which had real time capabilities (an obstacle that took me a while to overcome). I am currently in the stages of adding video and audio calling, I have only ever made calling on websites, so this will be my first time attempting to do so within a mobile app. This project works well on iOS, and I am still overcoming design and layout related issues to the Android app version.
