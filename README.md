# Rewsta-React
The origins of this project were the https://github.com/ethanphp/CofD-X project. What was the original web version, got built into a Flutter version and then now into this React version. This version also switched to the 'Rewsta' brand. It worked with a similar layout to Twitter (X), but focused on only showing posts from people you follow, on a chronological only feed. It also included direct messaging, which had real time capabilities (an obstacle that took me a while to overcome). Whilst this project worked well on iOS, the most recent times I worked with it I struggled getting it to work effectively on Android. 

Perhaps a project to revisit in the near future?
